# 04 · 模型与数据适用范围

> 原则：**展示名本地化 ≠ 模型已具备中国数据能力。** 本文件逐个说明平台可调用的模型、其训练数据、单位口径与不可外推的边界。

## 一、作物种植推荐模型（已接入，可用）

| 项目 | 内容 |
| --- | --- |
| 权重 | `crop_recommendation/model/rf_model.pkl`（RandomForest）、`crop_recommendation/model/label_encoder.pkl` |
| 框架 | scikit-learn（上游用 1.5.1 训练，本地以 1.9.1 加载，会有 `InconsistentVersionWarning`，推理结果一致） |
| 输入特征（7 项，顺序固定） | N（氮）、P（磷）、K（钾）、temperature（℃）、humidity（%）、ph、rainfall（mm） |
| 输出 | 22 类作物之一；结果页同时显示英文类别名（便于追溯映射） |
| 训练数据 | 印度公开农业数据集（crop recommendation 经典数据集），非中国田间数据 |
| 类别 | apple, banana, blackgram, chickpea, coconut, coffee, cotton, grapes, jute, kidneybeans, lentil, maize, mango, mothbeans, mungbean, muskmelon, orange, papaya, pigeonpeas, pomegranate, rice, watermelon |
| 常见输入范围 | N 0–140、P 5–145、K 5–205、温度 8–45℃、湿度 14–100%、pH 3.5–10.0、降雨 20–300 mm |
| 越界处理 | 超出上述范围时结果页给出「适用范围提示」，说明可靠性下降；仍返回模型原始输出，不做修饰 |
| 适用地区 | 仅说明模型训练分布；**不能**据此推断中国具体县域的产量或品种适应性 |
| 建议用法 | 作为「先排除明显不合适作物」的初筛，随后结合当地农技部门意见与小区试验 |

### 实测记录

输入 `N=90, P=42, K=43, 温度=20.8, 湿度=82, pH=6.5, 降雨=202` → 模型输出 `rice`（页面显示「水稻」），接口 `POST /crop/predict` 返回 200。

## 二、科学施肥建议（规则库，非机器学习）

| 项目 | 内容 |
| --- | --- |
| 实现 | `agri_utils.recommend_fertilizer()`（上游规则库） |
| 输入 | 作物、土壤 pH、生育期、近 7 天降雨、近期气温 |
| 输出 | 肥料类型、NPK 参考比例、公斤/亩用量范围、管理提示 |
| 依据 | 作物养分需求（高氮/高磷/高钾）+ 土壤 pH 调整（酸性土壤提示石灰调理、碱性土壤提示关注 Fe/Zn）+ 降雨提示推迟施用 |
| 换算 | 用量区间为 kg/ha，页面按 **1 公顷 = 15 亩** 换算为 kg/亩 |
| 限制 | 未使用土壤检测值时不能作为处方；**不输出农药剂量**；置信度 0.65 是规则库自评分，不是统计准确率 |
| 示例 | 水稻、pH 5.2、营养生长期、近期降雨 120mm → 尿素（46-0-0），5.3–8.0 公斤/亩，提示「土壤偏酸 + 近期降雨较大宜推迟施用」 |

## 三、植物病害模型（默认禁用）

| 项目 | 内容 |
| --- | --- |
| 权重 | `Plant Disease Detection/plant-disease-model.pth`（38 类 PlantVillage） |
| 网络 | 仓库内 `model.py` 的 `PlantDiseaseNet`（卷积 + 残差块 + 自适应池化） |
| 预处理 | Resize(256,256) → ToTensor → ImageNet 归一化（与 notebook 一致） |
| 类别 | 38 类，含番茄（9 类）、马铃薯（3 类）、玉米（4 类）、苹果（4 类）、葡萄（4 类）、辣椒、桃、草莓、樱桃、南瓜、豆类、柑橘等 |
| **实测结果** | 对项目自带 33 张测试图推理，**所有样本**（番茄早疫病/晚疫病/健康/黄化曲叶病毒、马铃薯早疫病/健康、玉米锈病/健康、苹果黑星病/锈病）均输出 `Tomato___healthy`，置信度约 1.00 |
| 结论 | 权重或标签映射损坏，模型不具备可用的病害判别能力 |
| 处理 | `ENABLE_PLANT_MODEL=0`（默认）→ 服务端拒绝推理并返回明确原因；页面显示「模型自检失败，图片识别已禁用」；不返回任何猜测结果 |
| 自行验证 | 安装 `requirements-cn-ml.txt`（torch/torchvision），设置 `ENABLE_PLANT_MODEL=1`，`PLANT_MODEL_SELF_CHECK=true` 时会用项目自带样本自检，仍不一致会再次禁用 |
| 合规提示 | 即便模型可用，PlantVillage 也不含中国检疫性病害，输出仅可作初筛；药剂必须核对在中国登记的作物、防治对象、标签剂量与安全间隔期 |

## 四、AI 助手（DeepSeek / OpenAI 兼容）

| 项目 | 内容 |
| --- | --- |
| 接口 | `POST {DEEPSEEK_BASE_URL}/chat/completions`，`Authorization: Bearer $DEEPSEEK_API_KEY` |
| 默认模型 | `deepseek-chat`（可通过 `DEEPSEEK_MODEL` 改为 `deepseek-reasoner` 等） |
| 系统提示约束 | 默认简体中文；建议必须可执行；不得编造数据；农药需核对登记标签；政策/金融内容需注明以官方公告为准 |
| 降级 | 无 Key、401、超时、5xx → 本地中文规则库，界面标注「离线规则回答」或「在线失败 · 本地规则」 |
| 规则库覆盖 | 水稻、小麦、玉米、番茄、施肥、灌溉、病虫害、行情、账号使用 |
| 未覆盖行为 | 明确回复「本地规则库没有覆盖这个问题」，并提示可用工具 |
| 图片 | DeepSeek 文本模型不识图；图片由本地模型负责，模型不可用时如实说明 |

### 关于当前环境中的 DeepSeek 凭证

审计环境内已存在 `DEEPSEEK_API_KEY`（`sk-` 前缀，35 字符），但直接请求 `api.deepseek.com` 返回：

```
401 Authentication Fails, Your api key: ****caad is invalid
```

因此本次所有在线问答测试均走**降级路径**，界面与接口都如实标注。填入有效 Key 后无需改代码即可切换为在线模式。

## 八、术语与单位换算速查

| 换算 | 结果 |
| --- | --- |
| 1 公担（quintal） | 100 千克 |
| 1 公顷 | 15 亩 |
| 1 英亩 | ≈ 6.0703 亩 |
| kg/ha | kg/亩 = ÷ 15 |
| °C | 摄氏度，界面统一 `℃` |
| INR → CNY | **不做等值替换**；历史样例价格按演示汇率折算并标注 |
