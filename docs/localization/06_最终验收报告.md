## 三、缺陷修复概览

共记录并修复 **32 项**上游缺陷（详见 `03_功能复现与缺陷记录.md`），其中 13 项为阻断级：

- `translations.js` 破损 JSON 导致整站脚本中断
- `app.py` 缺 Key 拒绝启动
- `backend/models/__init__.py` 导入即崩溃
- `sanitize_input` 参数不匹配导致注册 500
- `auth_service.py` 缩进错误
- 作物推荐模型路径与结果页端点错误
- `disease.js` 调用被注释函数
- 聊天页 CSP 拦截本地图标字体
- Windows 缺 `.woff2` MIME 导致字体被拒
- 社区 / 联系页请求不存在的接口与跨境 API
- `contact.html`、`scheme.html` 上游重复脚本块导致 `Unexpected token '<'`
- `mobile-main.html` / `organic.html` 脚本语法错误

## 四、诚实性与风险说明

| 风险 | 实际情况 | 平台处理 |
| --- | --- | --- |
| DeepSeek 密钥失效 | 环境中的 Key 返回 `401 Authentication Fails` | 全站自动降级为本地规则库，界面标注「离线规则回答」；填入有效 Key 即恢复在线能力，无需改代码 |
| 病害模型不可用 | 33 张测试样本全部输出 `Tomato___healthy`（置信度≈1.00） | 默认禁用图片推理，接口返回 `model_unavailable` 并写明原因；页面按钮置灰并提示不能替代田间诊断 |
| 产量预测未接入 | 独立 Flask 应用、表单为空、输出单位未在中国口径标定 | 保留源码与权重，不挂入主站导航，文档说明其状态与运行方式 |
| 政策数据时效 | 补贴政策随地区与年度变化 | 只提供官方入口与政策方向，不写金额与截止日期，页面标注需核实 |
| 商城与社区数据 | 全部为本地演示样例 | 页面顶部说明条 + 每张卡片标签 + 统计区说明，不提供支付与担保 |
| 移动端 | 仅 Chrome 设备模拟验证 | 建议上线前补真机验证 |
